# Enterprise NYC Taxi Data Analytics Platform

An enterprise-style, metadata-driven data engineering
platform built using Azure Synapse Analytics.

## Technology Stack

- Azure Synapse Analytics
- Azure Data Lake Storage Gen2
- Apache Spark and PySpark
- Delta Lake
- Synapse Pipelines
- Serverless SQL
- GitHub and CI/CD
- Power BI

## Architecture

Landing → Bronze → Silver → Gold → Analytics

## Development Principles

- No unnecessary hardcoding
- Metadata-driven processing
- Reusable and modular code
- Incremental data ingestion
- Data quality and validation
- Secure authentication
- Environment-independent deployments
